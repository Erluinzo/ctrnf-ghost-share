Ghost Sharing 1.2.0 - by Onur

Race other players' Time Trial ghosts and share your own.

SHARE: in the Time Trial ghost menu, press R1 on your own ghost. A message
shows the file and its folder. Send that .ctrghost file. With Replay Mode,
a .crr file of the same run is there too: the full race, to watch exactly
(it goes in the RaceReplay folder; Ghost Viewer then also plays the ghost
exactly). The ghost works without it.

RACE ONE: close the game, put the .ctrghost file (original name) in
  <OCTR folder>/mod-state/user/data/ghosts/
(create the folder if needed). It appears in that track's ghost menu with the
sharer's name. Shared ghosts unlock nothing.

USA and EU players can share ghosts.
Game: CTR Nitro-Fueled 1.21 on the OCTR launcher. This ZIP is for USA
(CUSA13795); the -eu ZIP is for EU (CUSA14876). Enable only yours.
Install: Mods > Add files, choose the ZIP, enable it, restart the game.

1.1.0: EU edition; the export message says where the file is.
1.2.0: with Replay Mode, the export also gives the run's full race (.crr).
